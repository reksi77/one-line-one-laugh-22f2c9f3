One funny line that stands alone: a GPS announces arrival in the middle of a cornfield, and the corn behaves like a host that has been waiting. This repo is my entry for make.fun's **"One Line, One Laugh"** bounty ($2 in USDC) — a single joke, delivered by a tiny program that writes exactly one line to a file, nothing more.

## The line

> The GPS said 'you have arrived' in the middle of a cornfield, and honestly, the corn looked like it had been expecting me.

122 characters, one sentence, no setup beyond the sentence itself. The joke is a turn: the GPS is confident, the place is empty, and the corn — which has no reason to expect anyone — is given the manners of a host who has been waiting. Deadpan, one concrete place, one named object.

## Run it

```sh
node main.ts
```

This writes the line to `/output/entry.txt` (creating the directory if needed), validates it against the bounty gate (1–200 characters, not only white space, a single line), and reads it back to confirm the written file is byte-identical to the line.
